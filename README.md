# Smaranika Studio — website

Cinematic single-page site for Smaranika Studio (wedding photography & films), built with
Next.js 16 (App Router, TypeScript), Tailwind CSS 4, GSAP ScrollTrigger and Lenis.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Before launch

1. **Contact details** — copy `.env.example` to `.env.local` and fill in the WhatsApp number
   (digits with country code, e.g. `919876543210`), email, phone, location and social links.
   Empty values are simply hidden.
2. **Inquiry delivery** — set `NEXT_PUBLIC_INQUIRY_ENDPOINT` to a form service that accepts a JSON
   POST (Formspree, Web3Forms, Getform or your own API). Without it, "Check availability" opens
   WhatsApp with the couple's details pre-filled, and the site never claims a booking was stored.
3. **Replace the sample media** — every photo and film is a temporary Unsplash/Pexels sample.
   Put the studio's own work in `public/work/` and update the `src` values in
   [`src/content/site.ts`](src/content/site.ts). Then set `usingSampleMedia: false` in the same
   file to remove the footer credit, and delete the Unsplash entry in `next.config.ts` if unused.
4. **Real words only** — add genuine, client-approved testimonials to `testimonials` and verified
   figures to `stats` in `site.ts`. Both sections adapt automatically; nothing is invented.
5. Review the plain-language privacy notice in `src/app/privacy/page.tsx`.

## Where things live

| Area | File |
| --- | --- |
| All copy, photos, films, services, stories | `src/content/site.ts` |
| Brand colours, type, motion keyframes | `src/app/globals.css` |
| Sections (Hero → Finale) | `src/components/sections/*` |
| Scroll reveals (`data-reveal`, `data-mask`, `data-lines`, `data-parallax`) | `src/components/motion/Reveals.tsx` |
| Logo-derived monogram & icons | `public/brand/`, regenerated by `node scripts/brand-assets.mjs` |

Motion respects `prefers-reduced-motion`; touch devices keep native scrolling.
